## 三、调试串口

`USART3`（PB10=TX、PB11=RX），115200-8-N-1。
板上 **P10 跳线打到 ATK-MODULE 侧**，用 USB-TTL 接 ATK-MODULE 接口的 TXD/RXD。
（因为 PA9/PA10 被 TIM1 占用于 PWM，CH340 那条 USART1 不能用了。）

## 四、上电与调试顺序（按这个来，别跳步）

**第 0 步：不接电机、不接 24V**
只给开发板供电，打开串口，应看到启动横幅和自检结果。若 `FAULT 为低`，先查功率板供电与极性。

**第 1 步：只接 24V，不接电机，限流 0.5A**
看串口 `VBUS=` 是否与实际电压一致（不一致就是分压标定问题，差太多说明没接对引脚）。

**第 2 步：手转电机，验证霍尔**
看串口 `HALL=xxx`，转动时应按

```
100 → 110 → 010 → 011 → 001 → 101 → 100
```

循环变化，反向则倒序。**出现 000 或 111 就是霍尔线序/上拉有问题，先修这个再谈其它。**

顺手确认极对数：手转一圈，数上面这个循环出现几次，把结果填进 `main.c` 的 `MOTOR_POLE_PAIRS`。

**第 3 步：开环验证功率级（KEY0）**
接上电机但**空载**，限流 1A。按 KEY0，电机应以 2Hz 电频率缓慢起转，每 500ms 加速一次到 15Hz。

- 不转 / 抖动：三相线序接错，任意交换两根相线
- 一转就过流：死区不够或上下桥直通，先停下来查
- 转但很响：正常，六步换相本来就有换相转矩脉动

**第 4 步：霍尔闭环（KEY1）**
按 KEY1，电机应平稳起转，串口 `rpm` 显示实测转速。

- 起转后立刻反转、抖动、异响：**换相表与霍尔相位不匹配**，把电机任意两根霍尔线对调（HA/HB 或 HB/HC），重试
- 完全不转但开环能转：霍尔没触发中断，查 PB6/PB7/PC8 是否被 OLED/CAMERA 模块占用

## 六、已知限制（别当成能直接上车的代码）

1. **没有电流环、没有速度闭环**，只有软起动 + 固定占空比。下一步要加 PI 才谈得上"驱动"。
2. **相电流分辨率只有 81mA/LSB**（板载 GAIN=5V/V、2mΩ → ±165A 量程）。要做电流环，先把功率板 GAIN 跳到 20V/V（R43、R47 都不焊），量程变 ±41A。
3. **ADC 采样率约 7kHz**（480 周期采样时间，为了照顾 124k 分压的高阻源）。做电流环需要改短采样时间并降到双电阻采样。
4. **printf 是阻塞发送**，115200 下一行约 10ms，只能 1Hz 打印，严禁放进控制环。
5. **保护是"软"的**：靠 1ms 轮询 + 母线电流，不是逐周期限流。短路级故障仍要靠功率板自己的 VDS 保护（那玩意儿阈值很高，约 300A 起）。
6. 六步换相本身有换相转矩脉动，做底盘轮子够用；做机械臂关节末端会抖，那时候才需要 FOC。

## 七、下一步建议

- 先跑通 KEY0/KEY1，确认相序与霍尔顺序
- 加**速度 PI**：`Hall_GetSpeedRpm()` 已给实测转速，1kHz 环足够
- 再加**电流限幅**：用 `s_smp.ibus` 做外环限幅，配合 `DRV_SetDuty()` 的钳位
- 真要上 FOC，再考虑换 GAIN 档位 + 三相电流重构
